# ChapterExport_H マニュアル

**ChapterExport_H（チャプター書き出し）** は、YouTube・ニコニコ動画の概要欄に貼る**チャプター**（`0:00 オープニング` のような時刻とタイトルの並び）を、
プロジェクトから作ってコピーするプラグイン（Rust 製 `.aux2`）です。チャプターの元は、本体の**マーク**（マークリストのメモ）か、
決めた**レイヤーに置いたオブジェクト**です。編集で尺が変わっても、マークやオブジェクトを一緒に動かしておけば、開き直すだけで時刻が合います。

- **バージョン:** 0.3.0（2026-10-10: チャプターや警告が数百あっても重くならず、ボタンが押し出されないようにした。読み直しを間引き、ファイル出力の最中は前の結果を出したままにする。読んでいるシーンの名前を出す。0.2.0 は入力欄の確定と取り消し、0.1.0 は初版。どちらも 2026-10-10）
- **作者:** by HexBrowns
- **必要環境:** AviUtl2 **2.1.11** 以上

プロジェクトは書き換えません（行の「移動」ボタンで今のフレームを動かすだけです。本体の「元に戻す」の履歴も増えません）。

## 開き方

- **表示** メニュー → **チャプター書き出し**（ウィンドウ配置パネルからも選択可）

## 導入

1. [Releases](https://github.com/HexBrowns/ChapterExport_H/releases) から `HexBrowns.ChapterExport_H-v0.3.0.au2pkg.zip` をダウンロードし、AviUtl2 のプレビューへドラッグ&ドロップする
   （手で置くなら、中の `Plugin` フォルダを AviUtl2 のデータフォルダ（既定は `C:\ProgramData\aviutl2`）へコピーする）
2. AviUtl2 を再起動する
3. **表示** メニュー → **チャプター書き出し** でウィンドウを開く

導入されるのは `Plugin\ChapterExport_H\ChapterExport_H.aux2` だけです。

### ビルド（開発者向け）

リポジトリのルートで [aviutl2-cli](https://github.com/sevenc-nanashi/aviutl2-cli) の `au2` を実行します。
`release/` に、AviUtl2 のプレビューへドラッグ&ドロップして導入できるパッケージ（`.au2pkg.zip`）ができます。

```powershell
au2 release
```

## 使い方

### マークから作る（初期値）

1. レイヤー編集の上部（時刻の目盛りのあたり）を右クリックし、チャプターを始めたいフレームを**マーク**する
2. マークの**メモ**にタイトルを書く（メモの 1 行目がタイトルになる）
3. ウィンドウの **元** を **マーク** にすると、一覧に `0:00 タイトル` の形で並ぶ
4. **コピー** を押して、概要欄に貼る

### レイヤーのオブジェクトから作る

1. チャプター用のレイヤーを 1 つ決め、チャプターを始めたい位置にオブジェクトを置く（種類は問わない。図形・テキストなど）
2. タイトルは**オブジェクト名**。名前を付けていないテキストオブジェクトは、本文の 1 行目（制御文字は除く）を使う。
   名前の無いそれ以外のオブジェクトは出さずに警告する
3. ウィンドウの **元** を **レイヤー** にして、レイヤーを **名前**（レイヤー名と完全一致）か **番号** で選ぶ
4. **コピー** を押して、概要欄に貼る

一覧は、ウィンドウが見えている間、オブジェクトを動かしたとき（続けて動かしている間は 0.4 秒に 1 回）と、元がマークのときは 1 秒ごとに自動で読み直します。再生中とファイル出力の最中は間隔では読み直さず、ファイル出力の最中は前に読めた一覧を出したままにします（出力中もコピーできます）。すぐに読み直したいときは **読み直す** を押します。上には、読んでいるシーンの名前が出ます。
行の **移動** を押すと、そのフレームへ移ります。タイムラインに見えていないフレームなら、表示もそこへ送ります。

## 設定

| 項目 | 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 元 | マーク / レイヤー | マーク | チャプターをどこから読むか |
| レイヤー | 名前 / 番号 | 名前「チャプター」 | 元がレイヤーのときだけ出る。名前は一覧から選ぶか、手で書く |
| 書式 | YouTube / ニコニコ動画 / カスタム | YouTube | YouTube: `m:ss`、ニコニコ動画: `mm:ss`（どちらも 1 時間以上は `h:mm:ss`）。1 行は `時刻 タイトル` |
| テンプレート | 文字列 | `{time} {title}` | 書式がカスタムのときだけ出る。`{time}` 時刻、`{title}` タイトル、`{index}` 番号（1 から） |
| 時刻の形 | m:ss / mm:ss / hh:mm:ss | m:ss | 書式がカスタムのときだけ出る |
| 範囲選択があれば… | オン / オフ | オン | 本体のフレームの範囲選択があれば、その中のチャプターだけを出し、範囲の先頭を 0:00 にする |

数値や文字の欄（レイヤーの名前・番号、テンプレート）は、Enter かほかをクリックしたときに確定します（打っている途中の名前では読み直しません）。入力中に Esc を押すと、入力する前の値に戻ります。

設定はプロジェクトごとに保存されます（プロジェクトを保存したとき、そのプロジェクトに残る）。

## 書き出し

- **コピー**: クリップボードへコピーする
- **テキストに書き込む**: プロジェクトの隣の `<プロジェクト名>_チャプター.txt` に書き込む（UTF-8。同じ名前のファイルがあれば上書き）。
  プロジェクトを一度保存するまでは押せない

## 警告

書式が YouTube のときは、YouTube のチャプターの条件（先頭が 0:00 / 3 つ以上 / 各 10 秒以上）に合わないものに ※ を出します（行の警告は、時刻とタイトルの間に出ます）。
YouTube の条件に合わないと、概要欄に貼ってもチャプターになりません。ほかに次の警告を出します。

- タイトルが空のマーク・名前の無いオブジェクト（出さない）
- 前と同じ時刻（秒）のチャプター
- 範囲選択の外にあって出さなかったチャプターの数
- 名前で選んだレイヤーが見つからない

同じ理由の警告が 4 件以上あるときは、件数と先頭の 3 か所だけの 1 行にまとめます（マークを拍ごとに打っていても、一覧とボタンが押し出されないように）。警告の欄は高さに上限があり、多いときはその中でスクロールします。

## 注意

- 時刻は秒の切り捨てです（29.5 秒は `0:29`）
- 読めるのは**表示中のシーン**だけです。チャプターは書き出すシーン（たいてい Root）に置いてください
- ニコニコ動画の書式は、概要欄で時刻がシークのリンクになる条件を確かめていません
