# ChapterExport_H マニュアル

**ChapterExport_H（チャプター書き出し）** は、YouTube・ニコニコ動画の概要欄に貼る**チャプター**を、プロジェクトから作ってコピーする汎用プラグインです。
チャプターの元は、本体の**マーク**か、決めた**レイヤーに置いたオブジェクト**です。
編集で尺が変わっても、マークやオブジェクトを一緒に動かしておけば、開き直すだけで時刻が合います。
プロジェクトを書き換えることはありません。

- **バージョン:** 0.3.0
- **作者:** by HexBrowns
- **必要環境:** AviUtl2 **2.1.11** 以上

---

## 開き方

- **表示** メニュー → **チャプター書き出し**

## 導入

1. [Releases](https://github.com/HexBrowns/ChapterExport_H/releases) から `HexBrowns.ChapterExport_H-v0.3.0.au2pkg.zip` をダウンロードし、AviUtl2のプレビューへドラッグ&ドロップする。
   手で置くときは、中の `Plugin` フォルダをAviUtl2のデータフォルダへコピーする。
2. AviUtl2を起動する。
3. **表示** メニュー → **チャプター書き出し** でウィンドウを開く。

導入されるのは `Plugin\ChapterExport_H\ChapterExport_H.aux2` だけです。

---

## 使い方

### マークから作る（初期値）

1. レイヤー編集の上部、時刻の目盛りのあたりを右クリックし、チャプターを始めたいフレームを**マーク**する。
2. マークの**メモ**の 1 行目にタイトルを書く。
3. ウィンドウの **元** を **マーク** にすると、一覧に `0:00 タイトル` の形で並ぶ。
4. **コピー** を押して、概要欄に貼る。

### レイヤーのオブジェクトから作る

1. チャプター用のレイヤーを 1 つ決め、チャプターを始めたい位置にオブジェクトを置く。オブジェクトの種類は問わない。
2. タイトルは**オブジェクト名**。名前を付けていないテキストオブジェクトは、本文の 1 行目を使う。
   名前の無いそれ以外のオブジェクトは出さずに警告する。
3. ウィンドウの **元** を **レイヤー** にして、レイヤーを **名前** か **番号** で選ぶ。名前はレイヤー名と完全に一致させる。
4. **コピー** を押して、概要欄に貼る。

一覧は、ウィンドウが見えている間、オブジェクトを動かしたときに自動で読み直します。
元がマークのときは 1 秒ごとにも読み直します。
再生中とファイル出力の最中は間隔では読み直しません。
ファイル出力の最中は前に読めた一覧を出したままにし、コピーもできます。
すぐに読み直したいときは **読み直す** を押します。
上には、読んでいるシーンの名前が出ます。
行の **移動** を押すと、そのフレームへ移ります。タイムラインに見えていないフレームなら、表示もそこへ送ります。

## 設定

| 項目 | 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 元 | マーク / レイヤー | マーク | チャプターをどこから読むか |
| レイヤー | 名前 / 番号 | 名前「チャプター」 | 元がレイヤーのときだけ出る。名前は一覧から選ぶか、手で書く |
| 書式 | YouTube / ニコニコ動画 / カスタム | YouTube | YouTube: `m:ss`、ニコニコ動画: `mm:ss`。どちらも 1 時間以上は `h:mm:ss`。1 行は `時刻 タイトル` |
| テンプレート | 文字列 | `{time} {title}` | 書式がカスタムのときだけ出る。`{time}` 時刻、`{title}` タイトル、`{index}` 1 から始まる番号 |
| 時刻の形 | m:ss / mm:ss / hh:mm:ss | m:ss | 書式がカスタムのときだけ出る |
| 範囲選択があれば… | オン / オフ | オン | 本体のフレームの範囲選択があれば、その中のチャプターだけを出し、範囲の先頭を 0:00 にする |

レイヤーの名前・番号とテンプレートの欄は、Enterかほかをクリックしたときに確定します。
入力中にEscを押すと、入力する前の値に戻ります。

設定は、プロジェクトを保存したときにそのプロジェクトへ保存されます。

## 書き出し

- **コピー**: クリップボードへコピーする
- **テキストに書き込む**: プロジェクトの隣の `<プロジェクト名>_チャプター.txt` に書き込む。同じ名前のファイルがあれば上書きする。
  プロジェクトを一度保存するまでは押せない

## 警告

書式がYouTubeのときは、YouTubeのチャプターの条件に合わないものに ※ を出します。
条件は、先頭が 0:00、3 つ以上、各 10 秒以上です。
行の警告は、時刻とタイトルの間に出ます。
YouTubeの条件に合わないと、概要欄に貼ってもチャプターになりません。
他に次の警告を出します。

- タイトルが空のマーク・名前の無いオブジェクト。一覧には出さない
- 前と同じ時刻（秒）のチャプター
- 範囲選択の外にあって出さなかったチャプターの数
- 名前で選んだレイヤーが見つからない

同じ理由の警告が 4 件以上あるときは、件数と先頭の 3 か所だけの 1 行にまとめます。
警告の欄は高さに上限があり、多いときはその中でスクロールします。

## 注意

- 時刻は秒の切り捨てです
- 読めるのは**表示中のシーン**だけです。チャプターは書き出すシーンに置いてください
- ニコニコ動画の書式は、概要欄で時刻がシークのリンクになる条件を確かめていません
